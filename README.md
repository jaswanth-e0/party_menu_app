Users log in using their email and password. If the user is an admin and authentication is successful, a JWT token is generated and stored, allowing the user to access the application. Once logged in, the user is redirected to the **Menu** page, which displays different food categories such as **Veg, Non-Veg, Starters, Main Course, and Desserts**.

Users can browse the menu and click on any food item to view its detailed information, including its description, ingredients, and other details. They can also save their favorite recipes, which are stored in the browser's **localStorage**. Saved recipes can be viewed later and removed from the saved list whenever the user wants.
